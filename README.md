# AI Chatbot

A full-stack AI chatbot built with React, Node.js, Express, and Google Gemini API.

## Features

- AI-powered conversations using Google Gemini
- Real-time chat interface
- Conversation history
- Suggested prompts
- Loading states
- Error handling
- Clear conversation functionality
- Responsive design
- Secure API key handling using environment variables

## Technologies Used

- React
- Vite
- JavaScript
- Node.js
- Express.js
- Google Gemini API
- Google GenAI SDK
- HTML
- CSS
